# VeriBuild

VeriBuild is a South African construction marketplace that connects homeowners with verified contractors.

## Features

- Contractor verification system
- Project posting
- Quote comparison
- Homeowner and contractor profiles
- Construction project management

## Mission

To make finding trusted contractors safer, easier, and more transparent for homeowners across South Africa.
